# World News — 25 November 2026

An entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125): one 1024×1024 image that sums up Wednesday 25 November 2026 in 32 stories — 12 illustrated leads, a map with numbered pins, and 20 more briefs. An AI judge compares the images pairwise; the 50 highest-ranked entries share $100.

## How it works

`main.py` (Python 3.13, standard library only) copies `entry.png` byte-for-byte to the output directory. It uses no network, no clock, and no files outside this repository, so repeated runs write identical bytes.
